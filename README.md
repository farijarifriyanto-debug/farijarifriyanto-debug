# Halo, saya BotConnector 👋

[![Website](https://img.shields.io/badge/botconnector.id-AI%20Cloud-06305A)](https://botconnector.id/)
[![Free tier](https://img.shields.io/badge/coba gratis-Starter%20Rp0-22E6FF)](https://botconnector.id/id/go/start)

**BotConnector** menghubungkan AI cloud (GPT, Claude, Gemini, DeepSeek, Qwen), model lokal di komputer Anda, dan tools developer dalam satu akun. Mulai gratis di [botconnector.id](https://botconnector.id/) atau lewat [Web App](https://app.botconnector.id/).

## Repositori utama

| Repo | Untuk apa |
|---|---|
| [bccli](https://github.com/farijarifriyanto-debug/bccli) | Coding agent AI di terminal — `npm i -g @botconnector/bccli@next` |
| [switchboard](https://github.com/farijarifriyanto-debug/switchboard) | Agent harness open source, semuanya plugin — `npm i -g @botconnector/switchboard` |
| [BotConnector](https://github.com/farijarifriyanto-debug/BotConnector) | Workspace lokal-first: chat TUI, runtime llama.cpp, API OpenAI-compatible |
| [BotConnector-Chat](https://github.com/farijarifriyanto-debug/BotConnector-Chat) | App iOS/Android (chat, Riset Mendalam, Image Studio) |
| [BotConnector-Web](https://github.com/farijarifriyanto-debug/BotConnector-Web) | Sumber situs [botconnector.id](https://botconnector.id/) |
| [BotConnector-Desktop](https://github.com/farijarifriyanto-debug/BotConnector-Desktop) | Bridge desktop untuk Local AI, hardware, dan pairing perangkat |
| [BotConnector-Core](https://github.com/farijarifriyanto-debug/BotConnector-Core) | Fondasi production (Rust) |

## Coba dalam satu menit

```bash
npm i -g @botconnector/bccli@next
bccli login        # API key dari Workspace Anda
cd project-kamu && bccli
```

atau buka [app.botconnector.id](https://app.botconnector.id/) langsung di browser — ada model gratis di Starter.
